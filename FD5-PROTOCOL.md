# FD5 four-arm measurement protocol — recovery draft

The registered command is `npm run bench:fd5 -- --config tools/fd5-provisional-config.json --out /path/outside/repo/fd5-report.json`. The output path must be new. This command is **not authorized for a full run yet**. The recovery stop permits unit tests and a reviewed bounded smoke only with orchestrator clearance. The provisional 400 ms interface deadline in the example is diagnostic; it is not a D7 production choice.

The driver fixes three repetitions of 100 scheduled writes at 120 ms intervals plus 100 burst writes. It rotates four arms as `baseline, clip-only, interface-only, combined`; `interface-only, combined, baseline, clip-only`; `combined, baseline, clip-only, interface-only`. Each loaded arm uses the baseline from its own repetition. This produces 54 individual latency comparisons (overall, scheduled, burst p50/p99 for three arms and three repetitions) and nine throughput comparisons. Each latency must be at most 1.20× its paired baseline; throughput at least 0.95×; both sides must have zero missing writes. Any insufficient load invalidates that comparison. No average of repetitions substitutes for a failed cell.

The clip load reuses B2's corpus, 16 cycling slots, immediate overload retry, 100,000-attempt guard, and `scoreCaptureArm` without changing its semantics. The interface load has its own 16 cycling slots in this **explicit provisional configuration**. A slot owns one immutable range/content key, retries only an HTTP `skipped/overloaded` response, and retires all other outcomes. Corpus pages have 1, 4 and 16 mixed TS/TSX/Swift files; each after-content hash is unique. The writer, watcher, reader and durable health boundary are real. The corpus is historical synthetic reader input only; it never emits a live capture event. Load continues through the actual capture stop/drain, and all work uses fresh disposable store/worktree roots.

The scorer requires correlated internal admission traces before it can classify rejected, queued, running and failed work. It validates each returned file's path, source hashes, language version and hand-specified change content; a `ready` page with empty/cache-only work gives zero useful comparisons. It reports overload fraction and useful comparisons/sec by language, and requires continuous request coverage plus a complete fresh comparison and overload in each 1–2 second capture window. Queue and running timeouts are separate; a page with completed rows and a timed-out look-ahead still counts as one timed-out request. A timed-out look-ahead with no HTTP reason is reported separately pending contract adjudication. Missing or unclassified traces invalidate the denominator. A cap hit, exhausted corpus, missing response, drain failure or unverified cleanup invalidates the run.

## Integration prerequisites

The frozen FD4 runtime has no request-correlated admission, freshness, phase or actual-exit observer. The current driver therefore emits `validForD7:false` and marks interface evidence insufficient. It cannot turn HTTP status into an admission denominator or call a ready page a fresh parse. FD4 must add optional test-only, bounded, inert observers for:

- per-request admission disposition, queue/dispatch/settle with monotonic timestamps, workload and correlation key; HTTP errors must remain classifiable;
- per-file cache hit/miss and phase spans for scan, retention/CAS read, hash, worker/child startup, grammar load, parse/compare, serialization and HTTP completion;
- cancellation request and actual worker/child exit, including overlap with replacement;
- real coalesced clip waiters for a separate W diagnostic (the unique-key saturation load does not exercise W).

Observer data must stay in memory, avoid source bytes, have a fixed cap and report overflow as invalid. Compare tracing on/off overhead in a bounded smoke. The daemon must not set the observer and public HTTP bytes must be identical with and without it. The harness can then accept traces in `scoreInterfaceLoad`; until the wiring lands, `freshness` and admission remain unverified.
